# electrical power calculator

this is a simple python program for calculating electrical power, voltage, current and resistance.

the program uses different electrical formulas to calculate the values.

## features

- calculates power
- calculates voltage
- calculates current
- calculates resistance

## formulas

P = V x I

P = I x I x R

P = V x V / R

V = P / I

V = I x R

I = P / V

R = V / I

## how to use

run the power.py file and choose what you want to calculate.

then enter the values asked by the program.
